설치

릴리즈에서 AIModelTalk.zip을 받아 ~/Applications에 넣으세요. (macOS 14+)

서명되지 않은 앱이라 첫 실행 시 Gatekeeper 경고가 뜰 수 있습니다. 우클릭 → 열기, 또는 아래 명령을 실행하세요.

xattr -d com.apple.quarantine ~/Applications/AIModelTalk.app

직접 빌드: xcodegen generate --spec project.yml 후 ./build_and_run.sh debug macos

비용이 드나요?
앱은 무료·MIT 라이선스이며 유료 모델을 표시하지 않습니다. 각 공급자의 무료 티어 정책을 따릅니다.

API 키는 어디에 저장되나요?
macOS Keychain에만 저장됩니다. 코드·설정 파일에 남지 않습니다.
